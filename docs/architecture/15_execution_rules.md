# Execution Rules

# Branching Requirement

Create a dedicated branch before implementation.

Suggested branch:
feature/modular-company-intelligence-refactor

All future changes must be committed ONLY to this branch.

---

# Mandatory Execution Flow

Before major changes:

1. Analyze current implementation
2. Generate Graphify outputs
3. Identify reuse opportunities
4. Suggest alternate approaches if necessary
5. Then implement carefully

---

# Important Rule

Prefer:

* refactoring
* modularization
* cleanup
* extraction
* orchestration improvements

instead of:
complete rewrites.

---

# AI Optimization Rule

Target:
~4–6 AI calls per startup maximum.

Avoid:

* excessive orchestration
* agent-to-agent loops
* unnecessary enrichment fragmentation

---

# Delivery Expectations

Implementation should produce:

* clean modular architecture
* reusable code
* scalable enrichment pipeline
* field-level re-enrichment
* strong observability
* minimal regression risk
