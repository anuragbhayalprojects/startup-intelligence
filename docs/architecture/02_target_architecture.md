# Architectural Constraints

Avoid:

* excessive agents
* autonomous orchestration loops
* graph databases
* unnecessary normalization
* deeply nested pipelines

Prefer:

* modular services
* shared utilities
* reusable AI layers
* config-driven behavior
* observability-first systems
